# Class League 기획

학교 주제 웹앱 · **친구에게 낼 문제를 직접 만들며 복습하고, 매 경기 상대가 바뀌는 1:1 공부 리그**

기능·규칙의 자세한 정의는 [SPEC.md](SPEC.md), 구현 방법은 [ARCHITECTURE.md](ARCHITECTURE.md)에 있어요.

## 1. 왜 필요할까요?
> **상황 예시** — 중간고사 3주 전. 혼자 문제집을 펴면 30분도 못 가고, 정답을 맞혀도 금방 잊어요. 반 전체 공부 활동을 하려 해도 대진표·채점·순위를 관리할 사람이 부담스러워요. 친구끼리 문제를 내 주기로 해도, 이기고 싶어서 지엽적인 문제를 내는 일이 생겨요.

| 문제 | Class League의 해결 방법 |
|---|---|
| 혼자 하는 복습은 지루해서 오래 못 간다 | 경기마다 상대가 바뀌는 리그로 **‘이번 경기’라는 목표**를 만든다 |
| 문제를 풀기만 하면 이해가 얕다 | 상대에게 낼 **문제·정답·해설을 직접 만들며** 배운 내용을 다시 정리한다 |
| 틀린 문제는 한 번 보고 잊어버린다 | 틀린 문제가 **오답 노트**에 저절로 모여 시험 전에 과목별로 다시 본다 |
| 학급 활동은 대진표·채점·순위 관리가 힘들다 | 대진표·일정·채점·순위·**마감 처리를 앱이 자동**으로 한다 |
| 모두와 경기하면 시험 전에 끝내기 어렵다 | 종료 희망일까지 가능한 만큼만 하는 **시험 대비 단기 리그** |
| 이기려고 지엽적·장난 문제를 낼 수 있다 | **출제 범위**를 정하고, 범위 밖·오답·장난 문제는 **신고 → 관리자 무효** |

## 2. 해결책 한눈에: 축구 리그 방식의 공부
누구나 아는 규칙이라 설명이 필요 없어요.

| 축구 | Class League |
|---|---|
| 리그 | 학급 또는 친구 모임 하나 |
| 팀 | 참가 학생 한 명 |
| 경기 | 라운드마다 바뀌는 상대와 서로 문제를 내고 풀기 |
| 골 | 상대 문제를 맞힌 개수 |
| 승점 | 승 3 · 무 1 · 패 0 (+ 득실차) |

**핵심 가치**
1. **만들면서 복습:** 상대가 풀 문제와 해설을 쓰려면 개념을 정확히 알아야 해요. 문제를 만드는 것 자체가 공부예요.
2. **매 경기 새 목표:** 상대가 바뀌니 누구나 다시 이길 기회가 있어요. 져도 만든 문제와 오답은 공부로 남아요.
3. **운영은 앱이 자동으로:** 대진표·마감·채점·순위·몰수를 앱이 처리해서 관리자는 과목·범위·일정만 정하면 돼요.

## 3. 일반 퀴즈 앱·문제집과 무엇이 다를까요?
| | 일반 퀴즈 앱·문제집 | Class League |
|---|---|---|
| 문제는 누가? | 정해진 문제·선생님이 낸 문제 | **학생이 직접 만든다** (라운드마다 상대용으로 새로) |
| 공부 방식 | 풀기만 한다 | **만들기 + 풀기 + 해설** |
| 계속할 이유 | 점수·진도 | **1:1 경기·승점·순위**, 경기마다 새 상대 |
| 운영 | 사람이 문제·채점 준비 | 일정·대진·채점·마감 **자동** |
| 범위·공정성 | – | **라운드별 출제 범위**, 신고·무효 |
| 복습 | 따로 정리 | 틀린 문제 **오답 노트 자동 저장** |

## 4. 학교에 맞춘 설계
**리그 기간 방식** (학생 20명, 월·목 경기, 첫 경기 10/26 예시 — 앱의 일정 계산 결과)

| | 전체 리그 | 시험 대비 단기 리그 |
|---|---|---|
| 경기 상대 | 모든 학생과 한 번씩 | 같은 상대와 두 번 붙지 않게 전체 대진의 앞부분만 |
| 기간 | 19라운드 · 약 10주 (10/26 → 12/30) | 종료 희망일 11/15(3주)까지 **6라운드** |
| 순위 기준 | 승점 → 득실차 → 맞힌 수 | 경기당 평균 승점 → 평균 득실차 → 정답률 |
| 어울리는 때 | 학기 내내 하는 학급 활동 | 중간·기말고사 대비 |

**라운드별 출제 범위** (수업 진도에 맞춰)

| 라운드 | 수학 출제 범위 | 누가 정했나 |
|---|---|---|
| 기본 | 중간고사 범위 | 리그 만들 때 |
| 1라운드 | 이차방정식 (지난주에 배운 내용) | 관리자 |
| 2라운드 | 이차함수의 그래프 | 관리자 |
| 3라운드 | 중간고사 범위 | 따로 안 정함 → 기본 |

라운드가 시작되면 범위가 잠겨서 문제를 만드는 중에 바뀌지 않아요. 관리자가 깜빡해도 기본 범위를 쓰니 리그가 멈추지 않아요.

**학교에서 생기는 상황도 미리 생각했어요**
- **오늘 바로 시작:** 조건이 맞으면 만든 날 바로 1라운드
- **전학생 내보내기:** 그 학생과의 경기는 양쪽 모두 순위에서 빼고, 남은 상대는 쉬는 라운드
- **리그 삭제:** 모집 중(경기 기록 전)만 삭제, 진행 뒤에는 삭제 금지
- **리그 보관:** 끝난 순위·경기·오답을 남기고 다음 시험 리그로
- **닉네임 중복 방지:** 같은 반 같은 이름 구분 (띄어쓰기·대소문자 무시)
- **관리자는 운영만:** 공정하게 선수와 분리

## 5. 공정성 — 이기려는 마음이 공부를 망치지 않게
| 상황 | 결과 |
|---|---|
| 한 명만 [완성] 안 함 | 그 학생 몰수패 |
| 한 명만 제출 안 함 | 그 학생 몰수패 |
| 두 명 다 안 함 | 둘 다 패 |

- 몰수 경기는 0:0으로 기록하고 득실차에 넣지 않아요. 할 일을 안 한 사람이 이득을 볼 수 없어요.
- **신고 → 관리자 판정:** 무효면 푼 학생에게 정답 1점을 인정하고 점수·승패·순위를 다시 계산해요. 문제를 그냥 빼면 나쁜 문제를 받은 학생만 풀 문제가 줄어 불리하기 때문이에요.
- **판정 기한 3일:** 기한까지 판정하지 않으면 원래 점수로 확정돼요. 확인하지 않은 신고로 점수가 바뀌면 신고를 남발해 이득을 볼 수 있어서예요.
- **정보 보호:** 정답·해설은 제출 전까지 서버가 보내지 않아요. 관리자도 진행 중인 정답, 학생이 쓴 답, 학생 오답 노트는 볼 수 없어요.

> **알려진 한계와 대응** — 학생마다 상대가 낸 다른 문제를 풀기 때문에, 범위 안에서 아주 어렵게 꼬아 낸 문제를 완전히 막을 수는 없어요. 라운드별 출제 범위로 기준을 정하고, ‘불분명해요’ 신고와 관리자 판정, 끝난 경기의 학생 출제 문제 확인으로 줄여요.

## 6. 사용 시나리오 (중간고사 3주 전, 2학년 3반)
1. 선생님이 **시험 대비 단기 리그**를 만든다. 수학 2문제·영어 1문제, 월·목 경기, 종료 희망일은 시험 전날.
2. 학생 20명이 코드로 들어오고, 선생님은 미리 보기에서 **6라운드**를 확인한 뒤 시작한다.
3. 매주 진도에 맞춰 라운드별 범위를 정한다. 학생은 라운드마다 상대에게 낼 3문제와 해설을 만든다.
4. 상대 문제를 풀고 바로 채점과 해설을 본다. 틀린 문제는 오답 노트에 쌓인다.
5. 시험 전, 학생은 오답 노트를 과목별로 복습하고 선생님은 과목별 정답률로 약한 단원을 확인한다.

## 7. 기대 효과
| 누가 | 무엇이 좋아지나 |
|---|---|
| 학생 1명 | 3주 동안 문제 **18개를 직접 만들고**, 친구 문제 18개를 풀고, 틀린 문제를 오답 노트로 복습 |
| 공부가 어려운 학생 | 경기마다 상대가 바뀌어 **다시 이길 기회**가 있고, 져도 만든 문제와 오답이 공부로 남음 |
| 관리자(선생님·반장) | 대진표·채점·마감·순위를 직접 하지 않고, **정답률로 약한 과목**과 학생이 만든 문제를 확인 |
| 학급·친구 모임 | 원하는 사람만 참여하는 자율 공부 모임을 쉽게 만들고, 끝나면 보관 후 다음 시험에 다시 |
