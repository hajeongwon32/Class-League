# Class League 상세 명세 (기능·화면·규칙)

## 1. 앱 개요
- 학급 전체 또는 같은 학교 친구들이 서로 문제를 내고 풀며 승점을 쌓는 공부 리그 앱
- 비유: 학급·친구 모임 하나 = 리그 하나, 참가 학생 한 명 = 팀 하나
- 사용자: 리그에 참가하는 학생, 리그를 운영하는 관리자(선생님·반장·학생 등)
- 참여하고 싶은 사람만 6자리 리그 코드로 들어오므로, 학급 전체 활동과 친구끼리 하는 자율 공부 모임에 모두 사용할 수 있다
- 승 3점·무 1점·패 0점, 무승부, 득실차 등 이해하기 쉬운 축구 리그 규칙을 공부 경기에 맞게 사용한다

### 해결하려는 문제
| 문제 | Class League의 해결 방법 |
|---|---|
| 혼자 하는 복습은 지루해서 오래 못 간다 | 경기마다 상대가 바뀌는 리그로 “이번 경기”라는 목표를 만든다 |
| 문제를 푸는 것만으로는 개념을 깊이 이해하기 어렵다 | 상대에게 낼 문제·정답·해설을 직접 만들면서 배운 내용을 다시 정리한다 |
| 틀린 문제는 한 번 확인하고 잊어버리기 쉽다 | 틀린 문제를 오답 노트에 자동으로 모아 시험 전에 과목별로 다시 본다 |
| 학급 공부 활동은 관리자가 대진표·채점·순위를 직접 관리하기 어렵다 | 대진표, 일정, 채점, 순위, 마감 처리를 앱이 자동으로 한다 |
| 모두와 경기하려면 시험 전에 리그를 끝내기 어렵다 | 전체 리그와 시험 대비 단기 리그 중에서 기간 방식을 고른다 |
| 일부러 지엽적이거나 어려운 문제를 내는 것이 승리에 유리할 수 있다 | 출제 범위를 정하고, 범위 밖·오답·장난 문제는 신고해 관리자가 무효로 만든다 |

### 이용 흐름
1. 관리자가 리그 이름, 과목·문제 수·기본 출제 범위, 리그 기간, 경기 일정을 정해 리그를 만든다
2. 관리자가 6자리 코드를 공유하고 학생들이 원하는 리그에 참가한다
3. 관리자가 첫 경기 날짜와 실제 종료일을 확인한 뒤 리그를 시작한다
4. 라운드마다: 출제 범위 확인 → 문제 만들기·완성 → 상대 문제 풀기 → 자동 채점 → 승점·순위 반영
5. 관리자는 진행 상황, 과목별 정답률, 끝난 경기의 출제 문제를 확인하고 신고를 처리한다
6. 마지막 라운드가 끝나고 신고 처리가 완료되면 최종 순위와 상품을 발표한다

## 2. 사용자와 권한
| 사용자 | 할 수 있는 것 |
|---|---|
| 로그인하지 않은 사람 | 처음 화면 보기, 회원가입, 로그인 |
| 로그인한 사람(활성 리그 없음) | 코드로 리그 참가, 새 리그 만들기 |
| 학생(리그 참가자) | 출제 범위 확인, 이번 경기 문제 만들기, 상대 문제 풀기, 문제 신고, 순위·일정·지난 경기·오답 노트 보기 |
| 관리자(리그 생성자) | 리그 설정, 참가자 명단, 리그 시작, 라운드별 출제 범위, 진행 상황, 과목별 정답률, 끝난 경기의 출제 문제, 신고 처리, 최종 결과 관리 |

- 계정 하나는 동시에 하나의 활성 리그에만 속한다
- 관리자는 선수로 참가하지 않는다
  - 관리자가 경기에도 참가하고 싶으면 참가자 계정을 별도로 만들어 코드로 들어간다
  - 이유: 관리자는 진행 상황과 신고 내용을 볼 수 있으므로 선수에서 분리하는 편이 공정하다
- 관리자는 신고된 문제를 제외하고 진행 중인 경기의 정답·해설을 볼 수 없다
- 관리자는 학생이 실제로 입력한 답과 학생 개인 오답 노트를 볼 수 없다

## 4. 화면

### 공통·가입
- **처음 화면**: 앱 설명, 이용 방법 3단계, [로그인] [회원가입]
  - 아래에 **예시 화면 미리 보기**: 이번 경기, 채점 결과, 순위표, 오답 노트, 관리자 진행 상황을 실제 앱과 같은 디자인으로 보여 준다
    - "예시 화면"이라고 밝히고, 서버 데이터 없이 그린 화면이라 누를 수 없다 (버튼 모양만)
    - 넓은 화면에서는 두 칸, 휴대폰에서는 한 줄로 쌓는다. 맨 아래 [회원가입하고 리그 시작하기]
    - 이유: 가입 전에는 앱이 실제로 어떻게 생겼는지 알 수 없어, 써 볼지 정하기 어렵다
- 로그인·회원가입에서는 학생·관리자를 미리 고르지 않는다
  - 코드를 넣어 참가하면 학생, 리그를 만들면 관리자가 된다
- 회원가입 입력 설명
  - 아이디: “로그인할 때만 써요. 친구에게는 안 보여요”
  - 닉네임: “순위표에 보이는 이름이에요”
- 가입을 마치면 자동 로그인되어 로그인 후 첫 화면으로 이동한다
- **로그인 후 첫 화면(활성 리그 없음)**
  - 학생·관리자 카드: 역할(학생/관리자)과 제목, 할 수 있는 일 3가지 목록, 필요한 것(학생: 6자리 코드 · 관리자: 선수로는 참가하지 않음), 카드 폭 가득한 버튼
  - 학생 카드의 [코드 넣고 들어가기 →] → 6자리 코드 입력
  - 관리자 카드의 [리그 만들기 →] → 리그 만들기
  - 각 화면에 [← 뒤로가기]
- 이미 활성 리그가 있으면 학생 홈 또는 관리자 화면으로 바로 이동한다

### 학생 화면
- **모집 중 대기**: 리그 이름, 읽기 전용 리그 정보 카드(과목·문제 수·출제 범위·방식·요일·마감·만들기 기간·종료 희망일·상품), 참가자 명단, “관리자가 시작하면 대진표가 나와요”, [리그 나가기]. 넓은 화면에서도 두 칸으로 벌리지 않고 한 칸(640px)으로 가운데 둔다
- **리그 홈**
  - 리그 이름, 기간 방식, 현재/전체 라운드, 종료 예정일
  - 이번 경기: 상대, 과목별 출제 범위, 지금 할 일, 마감·남은 시간, 버튼
  - 바로 아래 오답 노트 카드: 아직 [이제 알아요]로 정리하지 않은 오답 수를 작은 숫자 배지로 표시. 틀린 문제가 생기면 “오답 3개 복습하기”처럼 안내
  - 순위표, 내 전체 일정, 지난 경기
- **문제 만들기**
  - 상대, 만들기 마감, 과목별 출제 범위
  - 문제 내용, 객관식/주관식, 보기·정답, 해설
  - 위와 아래에 [임시 저장] [뒤로가기], 아래에 [완성 ✅]. 완성한 뒤에는 위와 아래 모두 [다시 고치기]
  - 상태: 만드는 중 / 완성(마감 전 수정 가능) / 마감 후 잠김
  - 저장하지 않고 나가면 [저장하고 나가기] [저장 안 하고 나가기] [계속 쓰기]
- **문제 풀기**
  - 상대 문제, 안 푼 문제 수
  - [제출] 전 “제출하면 고칠 수 없어요” 확인
  - 제출 뒤 점수, 내 답, 정답, 해설, 문제별 [신고]
  - 틀린 문제가 있으면 “오답 노트에 담았어요” 안내
- **지난 경기**: 상대, 정상/몰수 결과, 점수, 내 답·정답·해설, 문제별 [신고]
- **오답 노트**
  - 리그 시작 뒤 학생에게만 표시
  - 과목, 라운드·상대, 문제, 내 답, 정답, 해설
  - 과목 필터, [이제 알아요 숨기기], [이제 알아요 ✅]

### 관리자 리그 만들기
카드를 순서대로 채운다.
1. **리그 정보**: 이름, 과목, 과목별 문제 수(기본 1), 과목별 기본 출제 범위(비우면 "자유 출제")
2. **리그 기간**
   - 전체 리그: 모든 학생과 한 번씩 경기
   - 시험 대비 단기 리그: 리그 종료 희망일 전까지 가능한 라운드만 진행 (종료 희망일 기본값: 3주 뒤). 날짜 칸 어디를 눌러도 달력이 열리고, [2주 뒤] [3주 뒤] [4주 뒤] [6주 뒤]로 빠르게 고를 수 있으며, 고른 날짜를 "11월 14일(토) · 오늘부터 21일 뒤 (3주)"처럼 보여 준다
3. **경기 일정**: 경기 요일(주 1~3회), 마감 시각, 문제 만들기 기간
4. **상품**(선택, 접힘): 최종 순위에 따라 줄 상품. 벌칙은 두지 않는다(공부를 즐겁게)
   - [+ 상품 추가]를 누르면 등수 칸이 다음 등수(1등 → 2등 …)로 미리 채워진다. 등수·내용 중 하나라도 비거나 끝 등수가 시작보다 작으면 그 칸을 빨갛게 하고 바로 아래에 이유를 보여 준다
   - 한 등수에는 상품을 하나만 정할 수 있다 (1~2등과 1~3등처럼 겹치면 화면과 서버 모두 거절)

- ③ 경기 일정과 ④ 상품 사이에 **📅 일정 미리 보기**가 있다: 예상 학생 수로 라운드 수·시작/종료일·라운드별 마감 계산

- 일정 설정 아래에 “월·목 경기 · 마감 22:00 · 만들기 자동”처럼 한 줄 요약을 표시한다
- 미리 보기에는 다음을 순서대로 표시한다
  - 총 라운드·약 몇 주, 시작·종료일
  - 한 라운드의 시작/만들기 마감/풀기 마감 표
  - 접을 수 있는 전체 라운드 표
- 단기 리그를 고르면 미리 보기에 “11월 1일(일)까지 4라운드 (모두와 다 붙으려면 7라운드)”처럼 가능한 라운드 수를 보여 준다
- 전체 리그가 6라운드 이상이면 “시험 전까지 끝내야 하면 시험 대비 단기 리그를 골라 보세요”라고 안내한다

### 관리자 리그 관리
- **모집 중**: 설정 변경, 코드 복사, 참가자 명단, 첫 경기 날짜, 실제 인원 일정 미리 보기, [이 일정으로 시작]
  - 화면 오른쪽 옆 [📝 할 일 1/3] 탭을 누르면 서랍이 열려 리그 시작까지 남은 단계(리그 만들기 → 학생 2명 이상 → 첫 경기 날짜 고르고 시작)를 ✅/⬜로 보여 준다. ✕나 Esc로 닫고, 리그를 시작하면 사라진다
- **진행 중·끝난 리그**: 리그 이름 카드 아래 메뉴 탭 [📋 진행 상황] [🚩 신고 (대기 수)] [📖 출제 범위] [📊 정답률]로 한 번에 한 가지만 보여 준다
  - 순위표는 탭과 상관없이 늘 탭 내용 아래에 보인다
  - 순위표에서 학생 행(어느 칸이든)을 누르면 그 학생 화면(만든 문제, 진행 중이면 [이 학생 내보내기])이 열린다. 순위표에 모든 참가자가 나오므로 따로 참가자 카드를 두지 않는다. 학생 화면의 순위표 이름은 누를 수 없다
  - 이유: 모든 카드를 한 화면에 쌓으면 신고가 쌓일 때 아래 메뉴(출제 범위 등)까지 한참 스크롤해야 한다
  - 탭은 아래로 내려도 위에 붙어 있고, 방향키(←→)로도 옮길 수 있다. 새로고침해도 고른 탭을 기억한다
  - 내용이 없는 탭은 숨긴다 (끝난 리그에는 출제 범위 탭이 없다). 처음 탭은 진행 상황
  - 넓은 화면에서도 읽기 좋은 폭(900px)으로 가운데에 한 칸으로 둔다. 휴대폰에서는 탭이 두 줄로 모두 보인다
- **진행 중**
  - 이번 라운드 진행 상황: 경기별 두 학생의 [완성]·제출 여부(✅ 함 / ⏳ 아직 / ❌ 마감까지 못 함 / ➖ 만들기에서 몰수돼 해당 없음), 아직 안 한 학생 수(모두 끝나면 몰수된 경기 수), 마감까지 남은 시간, 쉬는 학생
  - 현재/다음 라운드 과목별 출제 범위
  - 아직 시작하지 않은 라운드 범위 미리 입력·수정
  - 리그 전체 과목 정답률(막대)·학생별 과목 정답률(표, 50% 미만 강조, 기록이 없으면 "기록 없음")
  - 순위표에서 학생 이름을 누르면 그 학생이 만든 문제(끝난 경기만), 상대 정답 여부(⭕/❌/제출 안 함), 무효 여부
  - 신고 대기 목록: 한 줄 요약(라운드·과목·이유·출제·신고 학생)으로 10개씩 보여 주고 [더 보기]로 이어서 본다. 줄을 누르면 문제·정답·해설·범위가 펼쳐지고 거기서 [무효]/[문제없음]을 고른다. 처리한 신고는 [처리한 신고 보기]에 같은 모양으로 모은다
- 진행 중인 문제의 정답은 숨기고 “🔒 경기가 끝나면 볼 수 있어요”라고 표시한다
- **끝난 리그**: 최종 경기 순위, 상품, [📚 리그 닫고 새 리그 만들기] (처리하지 않은 신고가 있으면 판정 뒤에)
- **모집 중**: 리그 시작 카드 아래 [🗑️ 리그 삭제] (확인 창에 들어와 있는 학생 수를 알려 준다)
- [내보내기]: 모집 중에는 참가자 명단의 학생마다, 진행 중에는 순위표에서 학생 이름을 눌러 연 화면에서

### 지난 리그
- 학생은 끝난 리그의 최종 결과 카드에서 [📚 지난 리그로 보관하고 새 리그 시작]을 누른다 (신고 판정이 끝나 결과가 확정된 뒤)
- 첫 화면과 리그 홈의 [📚 지난 리그]에서 보관·닫은 리그 목록을 본다: 리그 이름, 방식, 학생 수, 내 순위, 우승
- 지난 리그를 누르면 우승·내 순위·상품, 최종 순위표, 내 경기 기록(상세 보기 포함)을 다시 본다

### 화면 공통
- 휴대폰에서도 사용하기 쉬운 반응형 화면과 PWA 설치 지원
  - 컴퓨터처럼 넓은 화면(가로 960px 이상)에서는 학생 리그 화면을 두 칸으로 나눈다: 왼쪽은 지금 할 일(이번 경기·오답 노트·일정·지난 경기), 오른쪽은 순위표·참가자. 관리자의 진행 중·끝난 리그 화면은 메뉴 탭으로 나눈다
  - 리그 만들기는 왼쪽에 설정, 오른쪽에 일정 미리 보기를 두어 설정을 바꾸면서 바로 확인한다
  - 문제 만들기·풀기처럼 글이 많은 화면은 읽기 좋은 폭으로 가운데에 둔다
  - 전체 화면 폭은 최대 1080px로 두어 큰 모니터에서도 옆으로 너무 퍼지지 않게 한다. 로그인·회원가입·코드 입력은 460px, 학생/관리자 고르기는 760px, 리그 만들기는 1000px
  - 이유: 한 줄로만 쌓으면 넓은 화면에서 양옆이 비고 스크롤이 길어진다
  - 홈 화면에 추가하면 앱처럼 열린다 (직접 그린 트로피 아이콘)
  - 인터넷이 끊기면 “인터넷에 연결되어 있지 않아요” 안내 화면을 보여 준다
  - 경기·로그인 같은 데이터는 기기에 저장하지 않고 항상 서버에서 받는다 (같은 기기를 쓰는 다른 사람에게 남지 않게)
- 키보드(Tab)로 이동할 때 지금 위치가 잘 보이고, 입력칸마다 이름이 있어 화면 읽기 프로그램으로도 쓸 수 있다
- 빈 화면에는 다음 행동 안내 표시
- 잘못 입력한 칸 가까이에 쉬운 오류 안내 표시
- 처리 중에는 버튼을 잠가 중복 요청 방지
- 위험한 행동은 앱 디자인의 확인 창 사용

## 5. 규칙과 예외 상황

### 아이디와 닉네임
- 아이디는 앱 전체에서 중복될 수 없고 다른 사용자에게 보이지 않는다
- 닉네임은 다른 리그에서는 같아도 되지만 같은 리그 참가자끼리는 같을 수 없다
  - 대소문자와 모든 띄어쓰기를 무시해 비교한다
- 참가할 때 중복되면 닉네임 변경 창을 열고, 변경 후 자동으로 다시 참가한다
- 학생 닉네임은 활성 리그가 없거나 모집 중일 때만 변경할 수 있다
- 관리자는 선수 기록에 나오지 않으므로 언제든 닉네임을 바꿀 수 있다

### 참가자와 리그 상태
- 리그 상태: 모집 중 / 진행 중 / 끝
- 참가자는 2명 이상 30명 이하
- 모집 중에는 학생이 참가·나가기 가능하고 관리자가 설정을 변경할 수 있다
- 진행 중에는 학생이 직접 나갈 수 없고 새 학생도 참가할 수 없다
  - 이유: 지고 있는 학생이 순위가 나빠질 때 나가 버리는 것을 막기 위해. 전학처럼 꼭 빠져야 하면 관리자가 내보낸다

### 리그 보관·닫기·삭제·내보내기
- 끝난 리그는 지우지 않고 보관한다. 리그가 끝나도 그 계정이 계속 묶여 있으면 다음 시험 때 새 리그를 할 수 없기 때문이다
  - 학생 [보관]: 리그 홈에서 사라지고 새 리그 코드를 넣을 수 있다. 순위·경기 기록·오답 노트는 그대로 남는다
  - 관리자 [닫기]: 새 리그를 만들 수 있다. 학생들의 기록은 지워지지 않고, 학생들은 각자 보관한다
  - 신고 판정이 끝나(또는 판정 기한이 지나) 최종 결과가 확정된 뒤에만 보관·닫기를 할 수 있다
- 끝난 리그에 있는 채로 다른 코드를 넣거나 리그를 만들면 “먼저 보관(닫기)해 주세요”라고 안내한다
- 리그 삭제는 모집 중일 때만 할 수 있다. 들어와 있던 학생은 리그에서 빠지고, 그 코드로는 더 들어올 수 없다
  - 이유: 시작한 뒤에 지우면 반 전체의 경기 기록과 오답이 한꺼번에 사라진다
- 학생 내보내기 (관리자)
  - 모집 중: 참가 기록만 지운다 (학생이 나가기를 한 것과 같다)
  - 진행 중: 그 학생은 순위표·명단에서 빠지고, 그 학생과 한 경기는 양쪽 모두 순위에 들어가지 않는다 (지난 경기에는 “순위 제외”로 표시)
    - 아직 결과가 안 난 경기의 상대는 쉬는 라운드가 된다
    - 이유: 늦게 만날 차례였던 학생만 공짜 승점을 받거나, 이미 그 학생에게 진 학생만 손해 보는 일이 없게 모두를 같은 기준으로 맞춘다
  - 남은 학생이 1명이 되면 리그가 바로 끝나고, 그때부터 신고 판정 기한 3일이 시작된다
  - 끝난 리그에서는 내보낼 수 없다
  - 내보낸 학생은 바로 다른 리그에 들어갈 수 있다
- 관리자가 선수로 참가하려면 별도 참가자 계정을 사용한다

### 리그 기간 방식
#### 전체 리그
- 모든 학생이 서로 한 번씩 경기하는 라운드 로빈
- N명이면 짝수는 N-1라운드, 홀수는 N라운드
- 홀수면 라운드마다 한 명이 돌아가며 쉬고 쉬는 라운드는 경기수·승점에 영향이 없다

#### 시험 대비 단기 리그
- 관리자가 리그 종료 희망일(보통 시험 전날 이전)을 정한다
- 앱은 첫 경기 날짜, 경기 요일, 마감으로 종료일까지 완전히 끝낼 수 있는 라운드 수를 계산한다
- 전체 라운드 로빈 대진의 앞부분만 사용해 같은 상대와 두 번 경기하지 않는다
- 학생 수가 짝수면 모든 학생의 경기 수가 같다
- 학생 수가 홀수면 일부 학생의 쉬는 횟수가 달라질 수 있어 경기당 평균으로 순위를 정한다
- 2명 리그를 제외하고 가능한 라운드가 2개보다 적으면 너무 짧다는 경고를 표시한다

### 경기 일정
- 경기 요일은 월~일 중 1~3개이며 요일 사이를 하루 이상 띄운다
- 한 라운드는 경기 요일 00:00에 시작해 다음 경기 요일 전날의 풀기 마감 시각에 끝난다
- 마감 시각: 18:00~23:00(매시간) 또는 23:59, 기본 23:59
- 문제 만들기 기간: 자동(라운드 앞쪽 절반, 최소 1일) 또는 직접 선택
  - 어떤 라운드에도 풀기 기간이 최소 하루는 남아야 한다
- 문제 풀기는 만들기 마감 직후부터 시작한다
- 첫 경기 날짜는 리그 시작 시 선택한다
  - 조건을 만족하면 “오늘 · 바로 시작” 가능
  - 오늘이 경기 요일이 아니면 오늘부터 다음 경기 요일 전날까지가 1라운드
  - 오늘 시작은 만들기·풀기 기간이 각각 최소 하루이고 만들기 마감까지 3시간 이상 남을 때만 가능
- 다음 라운드와 리그 종료는 사람이 버튼을 누르지 않아도 시각에 따라 자동 처리한다
- 모든 기준 시각은 Asia/Seoul이며 DB에는 UTC로 저장한다

### 출제 범위
- 관리자는 리그를 만들 때 과목마다 기본 범위를 1~100자로 입력한다
  - 예: “중간고사 범위”, “교과서 3~4과”, “이차방정식~이차함수”
  - 제한하지 않으려면 “자유 출제”라고 입력한다
- 관리자는 아직 시작하지 않은 라운드의 과목별 범위를 따로 정할 수 있다
  - 주 1회: 지난 한 주 동안 배운 내용
  - 주 2~3회: 지난 경기 이후 배운 내용 또는 누적 범위
- 범위는 날짜에 따라 매일 자동 변경되지 않고 관리자가 라운드별로 변경한다
- 별도 범위를 정하지 않으면 해당 과목의 리그 기본 범위를 사용한다
- 라운드가 시작되면 범위가 잠기며 관리자도 바꿀 수 없다
- 학생은 이번 경기와 문제 만들기 화면에서 범위를 확인한다

### 문제 만들기·임시 저장·완성
- 문제는 라운드마다 해당 상대를 위해 새로 만든다
- 과목 1~5개, 과목별 1~10문제 (리그 만들기에서 범위를 벗어나면 그 문제 수 칸을 빨갛게 하고 바로 아래에 이유를 보여 주며, [리그 만들기]를 누르면 그 칸으로 이동한다). 과목이 5개가 되면 [+ 과목 추가]를 흐리게 하고 바로 아래에 "과목은 5개까지" 안내를 보여 준다
- 객관식 보기 2~5개, 중복 보기 금지, 정답 하나
- 문제·해설 1000자, 보기·주관식 정답 200자까지
- 해설은 비워 둘 수 있다
- [임시 저장]은 일부만 작성해도 가능하며 “아직 완성하지 않았다”는 뜻이다
- [완성]은 과목·개수·형식 조건을 모두 만족해야 가능하다
- [완성] 뒤에도 만들기 마감 전까지 [다시 고치기]로 수정할 수 있다
- 만들기 마감이 지나면 문제가 잠긴다
- 만들기 마감까지 [완성]하지 않으면 모두 작성해 임시 저장했어도 미완성으로 처리한다
- 완성하지 않은 동안 경고를 표시하고 마감 3시간 전부터 더 강하게 표시한다
- 저장하지 않은 변경 사항이 있을 때 나가면 저장 여부를 묻는다
- 상대가 제출하기 전까지 서버가 정답·해설을 상대 화면에 보내지 않는다

### 문제 풀기·자동 채점
- 문제 풀기는 만들기 마감 뒤에만 가능하다
- 한 경기에 한 번만 제출하고 제출 뒤 수정할 수 없다
- 객관식은 보기 번호로 채점한다
- 주관식은 모든 띄어쓰기와 대소문자를 무시해 비교한다
- 제출 시 빈 문제는 오답, 제출 자체를 안 하면 몰수패다
- 제출 즉시 내 점수·답·정답·해설을 표시한다
- 화면을 열어 둔 사이 마감되면 제출하지 않고 “마감이 지났어요”라고 안내한다

### 경기 결과와 마감
- 정상 경기: 많이 맞히면 승, 같으면 무, 적으면 패
- 승 3점, 무 1점, 패 0점
- 두 사람이 모두 제출하면 바로 결과를 반영한다
- 마감 위반
  | 상황 | 결과 |
  |---|---|
  | 한 명만 만들기 마감까지 [완성] 안 함 | 미완성 학생 몰수패, 상대 몰수승 |
  | 둘 다 [완성] 안 함 | 둘 다 패(0점) |
  | 한 명만 풀기 마감까지 제출 안 함 | 미제출 학생 몰수패, 상대 몰수승 |
  | 둘 다 제출 안 함 | 둘 다 패(0점) |
- 몰수 경기는 0:0으로 기록하고 승패만 반영하며 득실차·맞힌 문제 수에서 제외한다
- 몰수 이유를 이번 경기와 지난 경기에서 표시한다
- 마감 뒤 누군가 리그 화면을 열면 밀린 마감 처리를 한꺼번에 실행한다
- 풀기 단계에서 몰수되어도 이미 제출한 사람의 풀이·오답 기록은 유지한다

### 순위
#### 전체 리그
1. 총 승점
2. 총 득실차
3. 맞힌 문제 수
4. 닉네임(가나다)

- 득실차는 정상 경기마다 `내가 맞힌 수 - 상대가 맞힌 수`를 더한 값이다

#### 시험 대비 단기 리그
1. 경기당 평균 승점(`총 승점 ÷ 경기 수`)
2. 경기당 평균 득실차
3. 정답률
4. 닉네임(가나다)

- 이유: 홀수 단기 리그에서는 일부 학생만 쉬어 총 경기 수가 달라질 수 있다
- 몰수 경기는 경기 수에는 포함하지만 점수·득실차 계산에서는 0:0으로 본다

### 문제 신고와 무효
- 신고는 공정성을 위한 필수 기능이지만, 학생이 모든 문제를 반드시 신고해야 한다는 뜻은 아니다
- 학생은 자신이 푼 문제를 리그 종료 전까지 문제당 한 번 신고할 수 있다 (채점 결과·지난 경기 상세의 문제마다 [🚩 신고])
  - "기타"를 고르면 자세한 이유(200자까지)를 꼭 적는다
- 신고 이유
  - 정답이 틀렸어요
  - 출제 범위를 벗어났어요
  - 문제나 보기가 불분명해요
  - 장난 문제예요
  - 기타
- 관리자는 신고된 문제의 내용·정답·해설·범위·신고 이유를 보고 [무효] 또는 [문제없음]을 선택한다
  - 신고된 문제는 진행 중인 경기라도 관리자가 볼 수 있다 (판정하려면 필요하기 때문)
  - 한 번 판정하면 바꿀 수 없다
- 무효 문제는 그 문제를 푼 학생에게 정답 1점을 인정한다
  - 이유: 문제를 제외하기만 하면 나쁜 문제를 받은 학생만 풀 수 있는 문제 수가 줄어 불리하다. 범위 밖·오답·장난 문제로 상대 점수를 낮추지 못하게 한다
- 무효 문제는 정답률, 오답 노트에서는 제외한다
- 무효 처리 후 경기 점수, 결과, 순위를 다시 계산한다
- 관리자가 어떤 문제를 왜 무효 처리했는지 해당 경기 참가자에게 표시한다
- 신고가 남아 있으면 리그는 끝 상태가 되어도 최종 결과에 “신고 처리 중”을 표시하고, 모두 처리된 뒤 최종 확정한다
- 판정 기한: 리그가 끝난 뒤(마지막 풀기 마감) 3일. 관리자 화면에 판정 마감까지 남은 시간을 보여 준다
  - 기한까지 판정하지 않은 신고는 자동으로 “문제없음”이 되고 최종 결과가 확정된다
  - 이유: 관리자가 판정을 잊어도 결과가 영원히 미확정으로 남지 않게. 확인하지 않은 신고만으로 점수를 바꾸면 신고를 남발해 이득을 볼 수 있어 자동 판정은 “무효”가 아니라 “문제없음”으로 한다

### 오답 노트
- 제출 시 틀리거나 비워 둔 유효 문제가 자동으로 모인다
- 본인만 볼 수 있다
- 무효 문제는 빠진다
- [이제 알아요]는 삭제가 아니라 숨기기이며 다시 볼 수 있다
- 경기 결과·순위에는 영향을 주지 않는다

### 관리자가 보는 기록
- 진행 중인 경기: 완성·제출 여부만 확인
- 끝난 경기: 학생이 만든 문제·정답·해설·상대 정답 여부 확인
- 학생이 입력한 실제 답과 개인 오답 노트는 볼 수 없다
- 정답률은 정상 제출된 유효 문제만 계산하고 몰수·무효 문제는 제외한다
- 한 문제는 상대 한 명만 풀기 때문에 같은 문제를 여러 명이 틀리는 일이 없다. 그래서 “많이 틀린 문제” 통계는 두지 않고 과목별 통계를 사용한다

### 보안·안전
- 모든 학생·관리자 권한과 경기 소유권을 서버에서 확인한다
- 비밀번호는 bcrypt 해시로 저장한다
- 로그인 5회 연속 실패 시 아이디 존재 여부와 관계없이 1분 잠근다
- SQL 값은 `?` 자리표시자로 전달한다
- 닉네임·문제·보기·해설의 HTML 태그를 실행하지 않고 글자로 표시한다
- 정답·해설은 권한과 경기 단계에 따라 서버 응답에서 제외한다
- 빈칸·너무 긴 글·잘못된 JSON·중복 요청에도 오류 화면 대신 쉬운 안내를 반환한다
- 비밀키는 `.env`에 저장한다
- 브라우저 보안 (`classleague/security.py`)
  - 로그인 쿠키: 다른 사이트에서 보낸 요청에는 붙지 않게(SameSite=Lax), 자바스크립트가 읽지 못하게(HttpOnly), https에서는 암호화된 연결로만(Secure)
    - http로 켠 내 컴퓨터에서는 Secure를 붙이지 않는다 (붙이면 로그인이 안 된다). 배포 서버 앞의 프록시가 알려 주는 https도 인정한다
  - 보안 헤더: 우리 사이트 파일만 실행(CSP, 인라인 스크립트·style 속성 금지), 다른 사이트 안에 넣기 금지, 파일 종류 짐작 금지, 다른 사이트로 주소 안 알림, https 강제(HSTS)
  - API 응답은 기기에 저장하지 않는다(no-store)
  - 2MB보다 큰 요청은 받지 않고 쉬운 안내를 돌려준다
- 개인정보는 아이디·닉네임만 받는다

## 6. 저장할 데이터
- 회원: 아이디, 비밀번호 해시, 닉네임, 가입 시각
- 리그: 이름, 코드, 관리자, 상태, 기간 방식, 종료 희망일, 과목·문제 수·기본 범위, 경기 요일, 마감 시각, 만들기 기간, 첫 경기 날짜, 순위 상품, 생성 시각
- 참가: 학생, 리그, 참가 시각, 상태(활성/보관/내보냄), 보관·내보낸 시각 (한 사람의 활성 참가는 하나만)
- 리그 추가 정보: 관리자가 닫았는지, 삭제했는지, 일찍 끝난 시각
- 라운드 범위: 리그, 라운드 번호, 과목, 별도 범위, 설정 시각
- 경기: 리그, 라운드, 시작·만들기 마감·풀기 마감, 두 학생, 문제 상태, 제출 여부, 점수, 결과, 몰수 여부·단계
- 문제: 경기, 만든 학생, 과목, 유형, 내용, 보기, 정답, 해설, 무효 여부
- 풀이: 경기, 문제, 푼 학생, 입력 답, 정답 여부, 제출 시각
- 신고: 신고 학생, 문제, 이유, 자세한 이유, 상태(대기/무효/문제없음/기한 지나 문제없음), 처리 시각
- 오답 노트 정리: 학생, 문제, [이제 알아요] 여부
- 로그인 실패 기록: 아이디 기준 실패 횟수, 잠금 종료 시각

## 7. 완료 기준
- 가입 직후 로그인되고 학생 참가 또는 관리자 생성을 선택할 수 있다
- 같은 리그 참가자 닉네임 중복을 막고 그 자리에서 변경 후 다시 참가할 수 있다
- 관리자가 전체 리그 또는 시험 대비 단기 리그를 선택할 수 있다
- 설정 변경 시 라운드 수·시작일·종료일·모든 마감이 즉시 다시 계산된다
- 단기 리그는 종료 희망일 전에 끝나며 같은 상대와 두 번 경기하지 않는다
- 홀수 단기 리그는 경기당 평균 기준으로 순위를 계산한다
- 기본 및 미래 라운드별 출제 범위를 설정하고 학생 화면에 표시하며 시작된 범위는 변경할 수 없다
- 문제를 라운드마다 새로 만들고 임시 저장·완성·재수정·마감 잠금이 규칙대로 동작한다
- 상대 제출 전에는 개발자 도구로 응답을 봐도 정답·해설이 노출되지 않는다
- 정상 제출 즉시 채점되고 두 사람 제출 후 결과·순위가 반영된다
- 만들기·풀기 마감 위반은 자동으로 몰수 처리되고 홀수 인원에서도 리그가 멈추지 않는다
- 전체 리그와 단기 리그의 순위 기준이 각각 정확히 적용된다
- 틀린 유효 문제는 오답 노트에 모이고 과목별 보기·[이제 알아요]가 동작하며, 학생 홈에 미정리 오답 개수 배지가 바로 갱신된다
- 범위 밖·오답·불명확·장난 문제를 신고하고 무효 처리 후 모든 관련 기록이 다시 계산된다
- 관리자는 진행 상황, 과목별 정답률, 끝난 경기의 출제 문제를 볼 수 있지만 실제 답·개인 오답 노트·진행 중 정답은 볼 수 없다
- 마지막 라운드와 신고 처리가 끝나면 최종 순위·상품을 표시한다. 순위표에서 상품 받는 등수는 맨 왼쪽 모서리에 상품마다 다른 색 선이 생기고, 순위표 아래에 색마다 어떤 상품인지 보여 준다
- 모든 시각·남은 시간은 한국 시간으로 표시하고 DB에는 UTC로 저장한다
- 로그인하지 않았거나 다른 리그·경기 사용자는 보호된 정보와 기능에 접근할 수 없다
- 이상한 입력, 긴 글, HTML 태그, 중복 클릭에도 서버 오류 없이 안전한 안내가 나온다
- 휴대폰에서 주요 화면과 표를 사용할 수 있고 PWA로 설치할 수 있다
- 끝난 리그를 보관(닫기)하면 같은 계정으로 새 리그에 들어가거나 만들 수 있고, 지난 리그의 결과·기록을 다시 볼 수 있다
- 모집 중 리그 삭제, 진행 중 학생 내보내기 후에도 순위가 모두에게 같은 기준으로 계산되고 리그가 멈추지 않는다
